# Deploy the plugin

- **Deploy Plugin to Plugins Folder** copies the manifest and Lua files to the console software's plugins folder.
- **Deploy and Reload on Console** also re-imports it into a plugin pool slot (set `ma3.deployAndRun.slot`).
- **Export Plugin to USB Stick** writes the files where a real console reads them.
- **Bump Version and Package Plugin** makes a zip to share.
