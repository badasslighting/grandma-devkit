# Find the rest

Open the Command Palette (**Ctrl+Shift+P**) and type `grandMA`. Only commands that fit the file you are in are listed: grandMA3 files hide the Telnet commands, grandMA2 files hide OSC and the designers.

Also in the Explorer sidebar: **grandMA3 Objects** (browse the console object tree, with or without a console). Variables have their own menu: **grandMA: Variables...** (turn the extra views off with `ma3.vars.enabled`).
