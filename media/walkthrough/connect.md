# Connect to your console

Running code on the console needs a small helper plugin, the **LuaBridge**. Click the status bar item (it says `grandMA3` or `grandMA2`) and choose **Install the LuaBridge plugin**.

| Console | What you do |
| --- | --- |
| grandMA3 onPC or console | Install the LuaBridge, then switch on OSC command input (the menu offers both). |
| grandMA2 onPC | Switch on Telnet (the remote command line) on the console, then install the LuaBridge. |

When the status bar shows a check mark, the bridge is running. Without a console you can still write code, use completion and run the checks.
